What it takes

From prototype to the app store

What I need from you

  • Brand kit: official logo files, colours, fonts, and approval to use your photos.
  • Menu check: confirm the prices, add service durations (they are not published), and review one price on the Luxury Colour list that looks like a typo.
  • Team & hours: stylists, working days, breaks, holidays.
  • Booking today: is a salon software in use, or is it manual?
  • Payments: a Razorpay (or similar) account for UPI and cards.
  • WhatsApp Business number for enquiries.
  • Policies: cancellation, late arrival, rewards rules.
  • Site access for the WooCommerce / myCRED connection.

How it is built

  • React Native (Expo) + TypeScript: one codebase for Android and iOS.
  • Backend: reuse WooCommerce where it fits, plus a small API for bookings and availability.
  • Sign-in: mobile OTP (Firebase or MSG91).
  • Push reminders: Firebase Cloud Messaging.
  • Payments: Razorpay, UPI first.
  • Admin: a simple web dashboard for the front desk.
  • Android build targets 64-bit ARM (arm64-v8a) phones, which keeps the install small.
